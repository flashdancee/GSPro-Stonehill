# Stonehill Unity workspace

The registered OPCD V4 BaseProject has been unpacked as
`Stonehill_Holes_01_02`. Its embedded `ProjectVersion.txt` requires Unity
2018.2.8f1. Do not allow another Unity version to upgrade the project.

Import the prepared RAW terrain from `../QGIS/exports/` using the settings in
the project root README. Final Unity/GreenKeeper building and GSPro testing
should be performed on Windows.
